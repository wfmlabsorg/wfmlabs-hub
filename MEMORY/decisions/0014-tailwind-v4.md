# ADR 0014: Tailwind v4

**Date:** 2026-05-09
**Status:** Accepted
**Authors:** Ted Lango, TARS

## Context

Seed doc v1.0 specified Tailwind v3.4. Tailwind v4 is current. Starting with v3 means migrating later.

## Decision

Tailwind v4 from Day 1. Ship current, avoid migration.

## Consequences

### Positive
- No future v3→v4 migration
- Latest features and performance improvements
- Better CSS-first configuration

### Negative
- Some shadcn/ui components may need v4-specific adjustments
- Slightly less community documentation (v4 is newer)
