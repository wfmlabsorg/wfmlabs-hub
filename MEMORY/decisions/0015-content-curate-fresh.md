# ADR 0015: Original Content Over Migration — Tools, Value Model, Expert Commentary

**Date:** 2026-05-09
**Status:** Accepted
**Authors:** Ted Lango, TARS

## Context

Seed doc v1.0 proposed migrating 50-100 items from Mighty. v1.1 initially proposed curating newsletters + papers + tools. Ted challenged this: republishing free content behind a login doesn't create value. WFM Labs has 13 deployed tools and a complete FOW-Value model with 207 research sources — rich assets that can be reframed as Hub-exclusive content.

## Decision

Launch with original and reframed content that doesn't exist elsewhere:

- **~10 tool pages** with methodology narratives, use cases, and embedded calculators (already live on Netlify)
- **3-5 original articles** adapted from FOW-Value material (value-based planning, second-order effects, cognitive portfolio model, value routing)
- **10-15 curated papers** from FOW-Value evidence library with Ted's expert "why it matters" and "caveats" commentary
- **5-8 topic landing pages** with editorial framing aggregating related content

Compass newsletter archive and Mighty content migrate in Phase 2 as library depth — not the launch hook.

## Alternatives considered

### Republish existing free content
Move newsletters and free papers behind Hub login.
**Rejected by Ted:** Doesn't create value. Members can already read this content. The Hub must offer something they can't get elsewhere.

### Full Mighty migration
Mine comment threads for buried content.
**Rejected:** Too much manual labor, uneven quality.

## Consequences

### Positive
- Launch content is genuinely exclusive to the Hub
- Tools are already deployed and working — just need metadata + narrative
- FOW-Value material (207 sources, 600+ claims) is a deep well for papers and articles
- Demonstrates the Hub's differentiated value immediately

### Negative
- Requires Ted to write/adapt 3-5 articles (medium effort)
- No newsletter archive on Day 1 (added Phase 2)
- Paper summaries need drafting from evidence library (TARS assists, Ted edits)
