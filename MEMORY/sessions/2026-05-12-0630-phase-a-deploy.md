## What we learned
- R2-synced filesystem strips execute permissions on native binaries (esbuild, sharp) — always use local filesystem for node_modules
- Cloud dir rm -rf is extremely slow; symlink approach doesn't work because R2 recreates directories
- `git show HEAD:path` is reliable way to extract files from git when working tree is corrupted
- Payload's auth config uses `AUTH_GOOGLE_ID` not `GOOGLE_CLIENT_ID`
